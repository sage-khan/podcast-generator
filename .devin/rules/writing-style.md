# Writing Style and Authorship Rules

## Authorship: non-negotiable

All commits, code, and documentation in this repository are attributed solely to the project's human author (Muhammad Danyal (Sage) Khan / `sage-khan`). This applies without exception to:

- **Git commits**: never add `Co-Authored-By: Claude`, `Co-Authored-By: <any AI system>`, or any other AI attribution trailer. Do not include one even when a default tool template suggests it, remove it before committing. The commit author is `sage-khan` only.
- **Documentation** (`README.md`, `docs/changelog.md`, `docs/diagnostics.md`, code comments, docstrings): no AI disclosure lines, "generated by," or assistant attribution of any kind.
- **Code and file headers**: author metadata reflects the human author only.

This is a public, open-source repository; commit history and attribution are visible to everyone who clones or views it on GitHub.

## No em dashes

Follow the em-dash rule already in `code-review-guidelines.md`: replace em dashes (—) with a period to start a new sentence, or a comma to continue it.
